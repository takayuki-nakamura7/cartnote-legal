買い物のデータは端末内に

CartNote はオフラインで使える買い物リストアプリです。アカウント、開発者が運営するアプリ用サーバー、自動同期、アクセス解析、広告はありません。アプリがリストや買い物のデータを開発者に自動送信することはありません。

リスト、保存済みアイテム、メモ、カテゴリ、表示設定、言語設定は端末内に保存されます。「おすすめ」には、端末内のチェック回数や関連する日時を使用します。この処理も端末内で行います。

バックアップと共有

利用者の操作で JSON 形式のバックアップを書き出したり、買い物リストをテキストで共有したりできます。バックアップには、リスト、保存済みアイテム、メモ、カテゴリ、言語設定、リストごとの設定が含まれます。共有テキストには、リスト名、まだチェックしていない買い物中のアイテム、カテゴリ名、メモが含まれます。

書き出した JSON ファイルには、CartNote 独自のパスワード保護や追加の暗号化はありません。クラウドストレージやメッセージアプリなど、選択した保存先・共有先での取り扱いには、そのサービスの方針が適用されます。

端末の設定によっては、OS が作成する端末バックアップにも CartNote のデータが含まれます。これはアプリの書き出し機能とは別の仕組みで、Apple または選択したバックアップ先で管理されます。

バックアップを読み込むと、確認後に現在のアプリ内データが置き換わります。データの統合は行いません。アプリ内でこの置き換えを元に戻すことはできないため、現在のデータを残したい場合は先に書き出してください。

データの保持と削除

アイテムをチェックしたり、買い物リストから外したりしても、保存済みアイテム自体は削除されません。後から再び追加できます。買い物リストから外すと、そのアイテムのメモは消去されます。

保存済みアイテムはアプリ内で削除できます。リストを削除すると、そのリストの保存済みアイテムも削除されます。全リストで共通のカテゴリは残ります。アプリを削除すると、端末内のアプリデータも削除されます。iOS の「App を取り除く」操作では、書類とデータが保持されます。

アプリ内の削除操作では、書き出したファイル、共有済みメッセージ、端末バックアップは削除されません。それぞれの保存先で管理・削除してください。

このウェブサイトについて

ウェブサイトの閲覧は、オフラインでのアプリ利用とは別です。このウェブサイトは GitHub Pages で公開しています。サイトの配信・運用のため、GitHub が閲覧者の IP アドレスやその他の技術的なリクエスト情報を収集する場合があります。取り扱いの詳細は、GitHub のプライバシーに関する声明をご覧ください。
